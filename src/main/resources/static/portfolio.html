项目作品集 · 学生成绩数据可视化分析平台

数据分析与可视化企业工学结合项目实践

同一份数据、同一套后端接口，三位成员各自独立完成一块可视化大屏，分别回答「整体学情如何」「多维度如何交叉」「学习时间究竟带来什么」三类问题。 数据为 UCI Student Performance 公开数据集，1044 条成绩记录（数学 395 条、葡语 649 条、33 个字段），经 pandas 清洗后写入 MySQL， 由 Spring Boot 提供 11 个统计与维护接口，前端用 ECharts 5.5 渲染。
