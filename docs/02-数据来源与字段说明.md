| `G3` | 期末成绩，**分析目标** | 0-20，= 0 视为缺考 |

| 字段 | 含义 | 取值 |

| `absences` | 一学期缺勤次数 | 0-93，长尾分布 |

## 三、派生字段（清洗阶段计算，5 个）

| 字段 | 含义 | 口径 |
|---|---|---|
| `is_withdrawn` | 缺考标记 | `G3 = 0 → 1`，其余 0 |
| `pass_g3` | 是否及格 | `G3 ≥ 10 → 1` |
| `grade` | 等级 | A ≥ 16 / B ≥ 14 / C ≥ 12 / D ≥ 10 / F < 10 / W 缺考 |
| `improvement` | 进步幅度 | `G3 − G2`，可为负 |
| `high_absence` | 高缺勤标记 | `absences > 20 → 1` |

辅助标识：

| 字段 | 用途 |
|---|---|
| `student_key` | 「科目-行号」构成，保证每一行唯一（原始数据无学号，13 属性组合会碰撞） |
| `person_key` | 13 个属性拼接，用于识别跨科目同一名学生 |

## 四、数据库结构

```
student（学生属性，1044 行）
  id · school · sex · age · address · famsize · p_status · medu · fedu
  · mjob · fjob · reason · guardian · traveltime · studytime · failures
  · schoolsup · famsup · paid · activities · nursery · higher · internet
  · romantic · famrel · freetime · goout · dalc · walc · health
  · student_key(UK) · person_key(IDX)

score（成绩事实，1044 行）
  id · student_id(FK→student.id, ON DELETE CASCADE) · course · g1 · g2 · g3
  · absences · is_withdrawn · pass_g3 · grade · improvement · high_absence
  · UK(student_id, course) · IDX(course, g3)

v_student_score（视图，只读）
  = student ⋈ score，向业务层暴露全部业务字段
```

设计要点：

1. **两表拆分**：学生属性只存一份（同一人两门课共享），成绩按「一人一课一行」存放，避免宽表冗余。
2. **视图固化联表**：业务查询几乎都要「学生属性 + 成绩」，用视图把 JOIN 固化成单表，MyBatis-Plus 可直接用 `QueryWrapper` 分页，也能让增删改精确落到源表。
3. **派生字段落库**：等级、及格标记等入库时算好，统计接口直接 `SUM/AVG`，避免每次查询重复写 `CASE WHEN`，也保证大屏、明细、导出三处口径一致。
4. **可重复执行**：入库前用事务内 `DELETE`（可回滚）而非 `TRUNCATE`（DDL 不可回滚）清空，失败不会留下半张表。

## 五、清洗流程（`data-pipeline/preprocess.py`）

1. 读取两份 CSV（`sep=";"`），统一列名大小写与命名。
2. 二值字段 `yes/no → 1/0`（8 个：schoolsup、famsup、paid、activities、nursery、higher、internet、romantic）。
3. `Pstatus`、`famsize` 等短字符串保留原值，数值列强制转 `int`（葡语文件 G1/G2 带引号）。
4. 派生 5 个指标字段（见上表）。
5. 输出 `output/clean_all.csv`、`output/clean_student.csv`、`output/clean_score.csv`。

## 六、入库与校验（`data-pipeline/load_data.py`）

- 用 SQLAlchemy + pymysql 连接 MySQL，先写 `student` 再写 `score`（`student_id` 取自插入后的自增主键），全程单事务。
- 二值列再做一次归一化兜底（`yes/no/True/False → 1/0`），防止上游漏转导致 `1366 Incorrect integer value`。
- 入库后自动校验三项：

| 校验项 | 期望值 | 实测 |
|---|---|---|
| 记录总数 | 1044（395 + 649） | 1044 ✅ |
| 数学期末均分 | 10.42 | 10.42 ✅ |
| 葡语期末均分 | 11.91 | 11.91 ✅ |
| 各等级人数之和 | = 记录总数 | 122+172+216+304+177+53 = 1044 ✅ |

## 七、口径说明（重要）

同一份数据在两处口径略有差别，看数时需注意：

| 口径 | 均分 | 及格率 | 用于 |
|---|---|---|---|
| **含缺考**（缺考按 0 分计入分母） | 数学 10.42 / 葡语 11.91 | 数学 67.1% / 葡语 84.6% | 图一、图三的 KPI 与「学习时长档 × 均分」 |
| **剔除缺考**（仅统计有效成绩） | 数学 11.47 / 葡语 12.38（按档位略不同） | 数学 73.9% / 葡语 91.7%（0 次缺勤组） | 图二的「分数段结构」「缺勤影响」 |

两种口径没有对错，但必须**在同一张图内保持一致**，并在图题或单位处标注。本项目的做法是：KPI 用含缺考口径（反映真实教学结果），分档对比用剔除缺考口径（避免 0 分拉平趋势）。
