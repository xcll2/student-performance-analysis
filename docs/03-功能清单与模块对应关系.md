# 功能清单与模块对应关系

## 一、总体模块划分

```
┌─────────────────────────────────────────────────────────────────────┐
│  展示层  member-a.html(图一)  index.html(图二)  member-c.html(图三)   │
│          portfolio.html（作品集入口，三作品互跳）                      │
├─────────────────────────────────────────────────────────────────────┤
│  服务层  StatsController   /api/stats/*    统计聚合（8 个接口）        │
│          DashboardController /api/dash/*   分科画像 + 相关性 + 明细     │
│          StudentController /api/students/* 分页检索 + 增删改           │
├─────────────────────────────────────────────────────────────────────┤
│  存储层  MySQL 8.3   student 表 + score 表 + v_student_score 视图      │
├─────────────────────────────────────────────────────────────────────┤
│  数据层  preprocess.py（清洗派生）→ load_data.py（事务入库，自带校验）  │
└─────────────────────────────────────────────────────────────────────┘
```

## 二、功能清单

### A. 数据工程（Python）

| 编号 | 功能 | 实现位置 | 说明 |
|---|---|---|---|
| A1 | 原始 CSV 读取与合并 | `data-pipeline/preprocess.py` | 分号分隔、列名统一、两科合并 |
| A2 | 二值字段数值化 | 同上 | yes/no → 1/0，与 TINYINT 对齐 |
| A3 | 派生指标计算 | 同上 | is_withdrawn / pass_g3 / grade / improvement / high_absence |
| A4 | 跨科目同人识别 | 同上 | 13 属性拼 `person_key`，识别 366 名双修学生 |
| A5 | 建库建表 | `data-pipeline/schema.sql` | student / score / 视图 / 索引 / 外键 |
| A6 | 事务化入库 | `data-pipeline/load_data.py` | DELETE + 事务，失败可整体回滚 |
| A7 | 入库自校验 | 同上 | 总数 1044、均分 10.42 / 11.91、等级和校验 |

## 四、运行与自测

### 启动

```bash
# 1) 建库 + 清洗 + 入库（只需一次）
mysql -uroot -p < data-pipeline/schema.sql
cd data-pipeline && python preprocess.py && python load_data.py

# 2) 启动后端（JDK 8）
mvn spring-boot:run          # 或 IDEA 运行 BackendApplication
```

### 访问

| 页面 | 地址 |
|---|---|
| 作品集入口 | http://localhost:8080/portfolio.html |
| 图一 袁正勇 | http://localhost:8080/member-a.html （`?p=2` 直达第 2 页） |
| 图二 熊闯 | http://localhost:8080/index.html |
| 图三 杨佳乐 | http://localhost:8080/member-c.html （`?tab=por` / `?tab=manage`） |

| 检查项 | 方法 | 结果 |

| 接口可用 | `curl` 逐个探测 11 个接口 | 全部 200 |

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `Port 8080 was already in use` | 上一个实例未退出 | `netstat -ano \| findstr :8080` 找 PID，`taskkill /PID <pid> /F` |
| 页面图例与轴文字重叠 | `legend` 与 `grid` 间隙不足 | 图例统一 `top:0`，`grid.top:30`、`grid.bottom:22~38` |
| 改了前端看不到变化 | 浏览器缓存 | 改 `?v=` 版本号 + Ctrl+F5 |
| `echarts is not defined` | CDN 不可达 | 已本地化 `js/echarts.min.js` |
| 图表全空、状态栏「连接中」 | 启动函数名不一致导致脚本中断 | 已修正为 `go(0)` / `loadDashboard()` 入口 |
| 入库报 `1366 Incorrect integer value` | yes/no 未转 1/0 | 清洗阶段转 + 入库前归一化兜底 |
