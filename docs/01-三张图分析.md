# 三张可视化大图逐图分析

> 对应课程作业《7.项目作品集（包含每个组员的作品）》中的三张作品截图。
> 每节依次说明：**表达的指标 → 图表类型 → 配色 → 布局 → 交互要点 → 需实现的视觉效果 → 本次复刻结果**。

三张图共用同一套数据与服务，但视角各不相同：

| 作品 | 负责人 | 页面定位 | 核心问题 |
|---|---|---|---|
| 图一 | 袁正勇 | 六页导航式分析大屏 | 整体学情如何？各因素如何影响成绩？ |
| 图二 | 熊闯 | 一屏式综合大屏（含增删改查） | 全量数据怎么在一屏内讲清楚，并能维护？ |
| 图三 | 杨佳乐 | 课程标签式专题大屏 | 单门课程内部，学习时长究竟带来什么？ |

## 图一：学习时间与考试成绩关系分析（袁正勇）

**页面形态**：带左侧章节导航的六页式大屏，截图展示第 01 页「全局概览」。

### 1. 表达的指标

| 位置 | 指标 | 数值 | 口径 |
|---|---|---|---|
| KPI 1 | 样本学生数 | 395 | 数学课记录数（清洗后） |
| KPI 2 | 期末平均分 G3 | 10.42 | 满分 20，含缺考计 0 |
| KPI 3 | 及格率 | 67.1 % | G3 ≥ 10 |
| KPI 4 | 平均学习时间档 | 2.04 档 | 1 档 <2h / 2 档 2-5h / 3 档 5-10h / 4 档 >10h |
| KPI 5 | 缺勤异常人数 | 5 人 | 一学期缺勤 > 30 次 |
| KPI 6 | 两课程分差 | 1.49 分 | 葡语均分 − 数学均分 |
| 主图 | 学习时间档 × 平均成绩 | 数学 10.05 / 10.17 / 11.40 / 11.26；葡语 10.84 / 12.09 / 13.23 / 13.06 | 每档内按科目分列 |
| 辅图 | 成绩档次构成 | 0-4 分 39、5-9 分 91、10-14 分 192、15-17 分 55、18-20 分 18 | 数学课，环形中心标注 395 样本 |
| 结论卡 | 三条 FINDING | 非线性收益 / 不及格经历最强负向 / 两课程系统性差异 | 由数据直接读出 |

### 2. 图表类型

- **分组柱状图**：学习时间档为类目，数学与葡语两色并列，柱顶标数值 —— 用于「同一维度、两个总体」的对比。
- **环形图（donut）**：成绩五档构成，中心留白放样本量 —— 环形比饼图更适合在中心承载一个汇总数字。
- **指标卡（KPI）**：六个竖切格子，标签 + 大号数字 + 单位 + 一行口径说明。
- **文字结论卡**：不是图表，但承担「把图读成一句话」的职责，是分析型大屏与展示型大屏的关键差别。

### 3. 配色

- 背景：近黑的深蓝 `#060d19`，面板 `#0b1728`，靠 1px 半透明青蓝描边 `rgba(58,124,165,.22)` 分层。
- 强调色：青绿 `#2fb0a6` / `#4fd1c5`，用于激活态导航、面板标题前的竖条、KPI 数字。
- 数据色：数学 = 蓝 `#4a8fd6`（自上而下渐变到 `#2f6fb5`），葡语 = 绿 `#35c48e`；等级色固定为 A 绿 / B 蓝 / C 青 / D 橙 / F 红 / W 灰。
- 文字：主 `#e6f1f7`、次 `#8fa8bd`、弱 `#5d7691` 三级，正文最小 9.5px，避免深色底上过细发灰。

### 4. 布局

- 顶栏 62px：左品牌（图标 + 中英文标题）、当前页徽标 `01 / 06 全局概览`、右侧更新时间 / 时钟 / 日期 / 刷新 / 全屏。
- 左导航 118px：六项竖排，每项「序号 + 名称」，激活项有左侧 2px 亮条 + 渐变底。
- 主区三行：KPI 条（约 86px）→ 图区（`2fr : 1fr` 两栏）→ 三条 FINDING 卡片；底部一行数据来源 + 分页点 + 快捷键提示。
- 全页用 `height: calc(100vh - 62px)` + `minmax(0,1fr)` 约束，1080p / 900p 均不出滚动条。

### 5. 交互要点

- 左侧导航切换 6 个章节，页面标题与右上 `SCREEN 0X / 06` 同步。
- 键盘 ← → 翻页，数字键 1-6 直达（答辩演示友好）。
- 刷新按钮重新拉取全部接口，时间戳更新。
- 全屏按钮进入 `requestFullscreen`。
- 图表按需渲染：切到某页才初始化该页图表，避免一次性创建 14 个实例。

### 6. 需实现的视觉效果

1. 深色玻璃质感面板 + 顶部一像素高光，卡片之间 10px 等距。
2. 柱状图自上而下的双色渐变，柱顶数值、图例右上角小方块。
3. 环形图中心汇总数字（两行：数字 + 「样本」），图例竖排右侧。
4. KPI 数字等宽字体对齐，单位用 11px 弱化色跟在数字后。
5. FINDING 卡片左侧 2px 竖条 + 从青绿到透明的横向渐变底。
6. 章节切换时不做花哨动画，保持「翻页即出图」的干脆感。

### 7. 本次复刻结果

文件：`src/main/resources/static/member-a.html` + `css/member-a.css` + `js/member-a.js`。

六页均实现为真实图表（非占位）：全局概览 / 学习时间专题 / 成绩分布 / 影响因素 / 三维分布 / 数据明细，共 14 张图 + 1 张可检索可导出表格；KPI 与三张截图数值逐项一致（395、10.42、67.1、2.04、5、1.49）。

## 图二：学生成绩综合可视化大屏（熊闯）

**页面形态**：单页满屏，无导航，全部信息一屏内呈现，右上角带「数据管理」。

### 1. 表达的指标

| 区域 | 指标 |
|---|---|
| KPI 条（6 项） | 1044 成绩记录总数、10.42 数学期末均分、11.91 葡语期末均分、78.0% 总体及格率、331 两门课双修人数、53 缺考记录 |
| 第一行 | 各科目期末均分对比、成绩等级分布（A→W）、及格率对比（G3 ≥ 10） |
| 第二行 | 分数段结构分布（剔除缺考）、性别与成绩差异、影响因素联动分析（13 维度下拉） |
| 第三行 | 学习时间 × 外出频率 → 期末均分热力、缺勤次数对成绩的影响（均分 + 及格率）、第二期 G2 与期末 G3 成绩散点 |

### 2. 图表类型

柱状图（均分 / 分数段 / 缺勤）、**堆叠柱状图**（等级分布，按科目分列、按等级堆叠）、**环形图 + 中心汇总**（及格率）、**分组柱 + 双折线**（性别差异：均分、及格率、优秀率三指标同框）、**双轴柱线组合**（维度联动、缺勤影响：左轴均分、右轴及格率）、**热力矩阵**（二维分档取均值）、**散点图**（G2→G3，两科着色）。

### 3. 配色

深蓝底 `#0a1424`，面板 `#101d33`，主强调青蓝 `#38bdf8`，数据色蓝 / 青 / 绿 / 橙 / 红，KPI 数字用青蓝发光；整体比图一更「科技感」，条纹与网格更密。

### 4. 布局

12 栅格三行：`span-3 / span-5 / span-4` + `span-4 × 3` + `span-3 / span-4 / span-5`，卡片高度 `minmax(0,1fr)`，图例统一置于顶部、`grid.bottom` 收紧到 22 — 这是为了解决「图例与 X 轴文字重叠」专门调过的参数。

### 5. 交互要点

- 右上「数据管理」→ 弹出列表（关键字 / 科目 / 性别 / 等级筛选 + 分页 + 编辑 / 删除）与表单（25 字段新增 / 编辑）。
- 任一变更多成功后，前端调用统一 `loadDashboard()` 重拉 8 个接口，KPI 与 9 张图**即时刷新**。
- 维度下拉 13 个选项联动第三行左图。
- 请求层 8 秒超时 + 3 秒自动重连（最多 10 次），解决「先开页面后起后端」与 keep-alive 失效挂起。

### 6. 需实现的视觉效果

1. 顶部光带 + 标题居中 + 两侧小标签（数据源标识、时钟）。
2. KPI 六格等宽、数字大号发光、单位弱化。
3. 每张图都有左上角标题栏（竖条 + 文字），右上角可放单位或控件。
4. 热力图使用青蓝到浅绿的连续色阶，并在右下角给出色带。
5. 弹窗与深色主题一致（半透明遮罩、圆角、主按钮渐变）。

### 7. 本次复刻结果

文件：`static/index.html` + `css/style.css` + `js/app.js`。即原有主页，本轮新增「作品集」入口，其余保持不动。

## 图三：课程标签式学习时长大屏（杨佳乐）

**页面形态**：单页 + 顶部三个标签（数学课 / 葡萄牙语课 / 学生数据管理），切换标签即整体换源。

### 1. 表达的指标

| 位置 | 指标 | 数值（数学课） |
|---|---|---|
| KPI | 学生总数 / 期末平均分 / 及格率 / 平均学习时长档 | 395 / 10.42 / 67.1 / 2.04 |
| 左上 | 每周学习时长分布 | <2h 105（26.58%）、2-5h 198（50.13%）、5-10h 65（16.46%）、>10h 27（6.83%） |
| 右上 | 各时长组平均分与及格率 | 均分 10.05 / 10.17 / 11.40 / 11.26；及格率 64.8 / 64.6 / 75.4 / 74.1 |
| 左下 | 期末成绩分段分布 | 0-4 分 39、5-9 分 91、10-14 分 192、15-20 分 73 |
| 中下 | 学习时长与期末成绩关系（散点） | 395 个点，按 4 个时长档横向抖动展开 |
| 右下 | 数学课 vs 葡萄牙语课 平均分对比 | 每档两柱并列 |

### 2. 图表类型

环形图、柱状图、**柱线双轴组合**、**带抖动的一维散点**（把分类型 X 上的重复点抖开，避免叠成竖线，并加 10 分及格虚线）、**分组柱状图**。

### 3. 配色

背景 `#050c1a`，面板 `#0a1730`，主强调宝蓝 `#2f6fd0` / `#5b9cf0`，辅青 `#35c4d8`、绿 `#35c48e`、橙 `#e8a33d`；标题用蓝→青的渐变文字，激活标签为实心蓝渐变 + 外发光。

### 4. 布局

三列不等宽（`1 : 1.42 : 1`）：
- 左列：学习时长环形图 / 分段分布柱状图，上下各半。
- 中列：一行四个 KPI（高 104px）+ 大散点图（占满剩余高度）。
- 右列：柱线组合图 / 两课对比图，上下各半。

中列特意做成「矮 KPI + 高散点」，因为散点需要面积，而 KPI 只需要一行数字 —— 这是与图一、图二最大的布局差异。

### 5. 交互要点

- 三个标签切换：数学 / 葡语切换时 4 个 KPI 与 5 张图全部换源；「学生数据管理」把图表区整体替换为可检索表格（关键字 / 科目 / 等级 / 分页 / 删除）。
- 30 秒定时自动刷新，并在顶栏显示最后更新时间。
- 删除记录后自动重载表格并刷新统计。
- 支持 `?tab=por` / `?tab=manage` 直接进入某个标签（便于演示与自测）。

### 6. 需实现的视觉效果

1. 渐变标题文字（蓝→青）+ 右侧胶囊标签组，激活项有蓝色投影。
2. KPI 卡片顶部一像素渐变高光条，数字宝蓝色。
3. 散点使用半透明填充 + 细描边，重叠处自然加深。
4. 分段柱按档位换色（蓝→青），柱顶标数值。
5. 表格斑马纹 + 等级彩色标签（A 绿 / D 橙 / F 红 / W 灰）。

### 7. 本次复刻结果

文件：`static/member-c.html` + `css/member-c.css` + `js/member-c.js`。5 张图 + 4 项 KPI + 1 个可用管理表格；切换课程、30 秒刷新、删除记录均实测通过。

## 三张图的共性设计语言

| 维度 | 共性做法 | 原因 |
|---|---|---|
| 背景 | 深色（近黑蓝）+ 径向渐变光晕 | 深色底让彩色数据更跳，投影小，适合投影仪/大屏 |
| 层级 | 面板描边 + 标题竖条 + 卡片间距 10px | 不用阴影堆叠，用细线切分，信息密度高但不糊 |
| 数字 | 大号等宽、单位弱化、口径小字注释 | 大屏第一眼要看数字，第二眼才看解释 |
| 图例 | 统一置顶或置右、8px 方块 | 避免与 X 轴标签抢位置 |
| 坐标轴 | 去掉刻度线、网格线极淡 | 减少视觉噪声 |
| 交互 | 都有「切换 → 全量重渲染」的统一入口 | 一个刷新函数管所有图，避免状态不一致 |
